# MultiServiços

Versão estática pronta para GitHub Pages. Substitua logo, capa, imagens dos produtos, capas e ficheiros pelos seus conteúdos reais. Altere o número WhatsApp e os links sociais nos HTML.

Para adicionar produto, duplique uma box `.product-card` em `loja.html`. Para adicionar trabalho, duplique uma box `.academic-card` em `trabalhos.html` e actualize os atributos, capa, descrição e link de download.
